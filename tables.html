Table Tags

Definition

Table tags are used to organize information into rows and columns.

Attributes

Attribute Role
colspan Makes a cell span multiple columns.
rowspan Makes a cell span multiple rows.

Example (code)


<table>

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Alex</td>
        <td>19</td>
    </tr>

</table>
