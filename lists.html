List Tags

Definition

List tags are used to organize information into ordered or unordered lists.

Attributes

Attribute Role
type Defines the type of ordered list numbering.
start Defines the starting number of an ordered list.

Example (code)


<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<ol>
    <li>First</li>
    <li>Second</li>
</ol>

Example (result)

  • HTML
  • CSS
  • JavaScript
  1. First
  2. Second
