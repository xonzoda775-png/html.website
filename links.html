Link Tags

Definition

The anchor tag is used to create hyperlinks to other pages or websites.

Attributes

Attribute Role
href Specifies the destination of the link.
target Specifies where the linked document opens.
title Provides additional information about the link.

Example (code)


<a href="https://www.google.com" target="_blank">
    Visit Google
</a>
