Media Tags

Definition

Media tags are used to add images, audio and video to a web page.

Attributes

Attribute Role
src Specifies the location of the media file.
alt Provides alternative text for an image.
controls Displays audio or video controls.

Example (code)


<img src="image.jpg" alt="Example image">

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>
