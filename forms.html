Form Tags

Definition

Form tags are used to collect information and input from website users.

Attributes

Attribute Role
action Specifies where form data is sent.
method Specifies how the form data is submitted.
type Defines the type of input field.
placeholder Displays a hint inside an input field.

Example (code)


<form>

    <label>Name:</label>

    <input type="text"
           placeholder="Enter your name">

    <button type="submit">
        Submit
    </button>

</form>
