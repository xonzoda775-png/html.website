Metadata Tags

Definition

Metadata provides information about an HTML document to browsers and search engines.

Attributes

Attribute Role
charset Defines the character encoding.
name Defines the type of metadata.
content Provides the metadata value.

Example (result)

The metadata is processed by the browser and is not normally displayed as visible page content.
